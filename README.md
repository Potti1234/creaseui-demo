# Northstar

A subscription revenue dashboard built with Foldkit, Vite, Tailwind and the supplied pinned CreaseUI registry.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

Open http://127.0.0.1:5187/. Working interactions include time ranges, customer search/status filters, sorting, pagination, account dialogs, CSV exports and responsive navigation.

```sh
npm run typecheck
npm run lint
npm run build
```

See [DISCOVERY.md](DISCOVERY.md) for component choices, setup, workarounds and validation artifacts.
