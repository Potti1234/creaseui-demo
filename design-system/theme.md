# Theme

The theme is generated by crease's preset compiler (`/create` on the crease site, or `npm run preset:build` in the crease repository). We don't edit the generated values by hand: we change a knob and generate again, so the code stays the record of the decision.

Preset code: `c41ST0kztg1aRr803UlnDN6.eyJkYXJrOmJvcmRlciI6Im9rbGNoKDEgMCAwIC8gOCUpIiwiZGFyazppbnB1dCI6Im9rbGNoKDEgMCAwIC8gMTIlKSJ9`

| Knob | Value | Why |
|---|---|---|
| style | `mira` | Compact controls: 28px buttons and inputs, 13px control text (D1, D4) |
| base | `zinc`, surface tint 0.004 | Cool, nearly neutral greys |
| accent | hue 277, chroma 0.16, lightness 55 | One calm indigo for focus, selection and the primary action |
| surface contrast | 6 | Sidebar and muted surfaces stay close to white, so content stays the loudest thing (principle 1) |
| dark page lightness | 19 | A dark theme that is grey-blue, not black |
| radius | 0.8 | 8px corners |
| shadow | 30, flat relief | Surfaces separate by tone and hairlines, not by depth |
| font | Inter, text scale 0.925 | 13px body text |
| overrides | dark `border` 8% white, dark `input` 12% white | Hairlines in the dark theme |

## Files

- `src/theme/tokens.css`: colours, radius, type scale and shadows, as CSS custom properties.
- `src/theme/geometry.css`: the `mira` control heights, keyed by each component's `data-slot` and `data-size`. It is registered in `eslint.config.js` as theme CSS.
- `src/theme/crease-preset.json`: the knob values, so the theme can be regenerated or reviewed.

`src/main.ts` loads both after crease's base theme in `src/styles.css`, so these values win.

## Regenerating

Generate the preset into a temporary folder, then split it the same way: rules that start with `:where([data-slot=…])` go to `geometry.css`, everything else to `tokens.css`. Remove the global `h1,h2,h3,h4`, `:root svg` and `*` rules, which crease's CSS policy rejects, and replace the Google Fonts import with `@import '@fontsource-variable/inter';`. Then run `npx creaseui-lint css`.
