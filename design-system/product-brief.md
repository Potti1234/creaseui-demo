# Crease Tasks: first local slice

Confirmed 2026-10-15: a task-management product using Linear as the design baseline,
Tailwind first, light appearance, desktop first, English copy and realistic work for
a small software/product team. Crease Tasks is a working name. The user will create
the remote repository named creaseui-demo.

The first review covers an issue list and quick editing: persistent navigation,
grouped issues, status/priority/assignee pickers, current-view search, a small filter
and ordering menu, quick creation, retained in-session drafts, local persistence
and a confirmed reset. It deliberately stops before a full detail route, board,
collaboration, backend, auth, reports or the complete guide series.

Data is synthetic. Alex Morgan is the active sample user. The two projects are
Workspace experience and Editor. List, project and personal views use the same
dataset, not separate decorative copies. Changes persist under one versioned key
on this browser's origin. Drafts survive closing the composer in this session;
drafts and view preferences do not yet survive reload.

Proposed values for review: a 236px navigation rail, 58px location header, 52px view
toolbar, 44px issue rows, 40px group headers and 32px regular action buttons with
extended hit areas. These are our design decisions, not measurements copied from
Linear. The status/priority/assignee vocabulary is shared across rows and creation.

Review locally first. Refine density, type, contrast, metadata and interaction
details on this same slice before building further screens or freezing chapter
branches. No remote repository, publication, or reviewed visual baseline exists yet.
